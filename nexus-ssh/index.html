SFTP file manager

Browse, edit, create and delete remote files and folders.

/03

Live dashboard

CPU, memory, disk, load and uptime pulled live from your server.

Docker manager

systemd services

Search units and control services, with confirmation prompts.

02 / INSTALL
  1. 01Download the APK

    Tap Download APK on your Android phone.

  2. 02Open the file

    Open the downloaded nexus-ssh.apk.

  3. 03Allow installation

    If asked, allow Install unknown apps for your browser.

  4. 04Add a server

    Open Nexus SSH and add your first server with +.

Only download from this page or the official GitHub Releases. The app is open source — read and build the code yourself.
